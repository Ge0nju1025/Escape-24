# 위기탈출 24

React + TypeScript + Vite 기반 자유 대화 비주얼 노벨. 서버는 Node Express / Gemini API입니다. 이전 1.0과 2.0 소스는 archive 아래에 보존합니다.

## 실행
`npm install` 후 `npm run dev`, http://127.0.0.1:5188/ 접속. API는 3018 포트입니다. 서버 전용 `.env`의 GEMINI_API_KEY, GEMINI_MODEL을 사용합니다. 키는 Git 제외이며 브라우저에 전달되지 않습니다.

## 구현
5개 에피소드, 자유 입력, Gemini 의미 분석, 서버의 필수 행동/위험 행동 분기 검증, 감정과 신뢰 변화, 최근 대화와 요약 기억, 자동 저장/이어하기, 대화 기록, 에피소드 선택, 제한된 Mock/Fallback, 타이핑 효과 및 모션 설정.

## 주요 파일
src/novel.tsx 화면과 저장, src/novel.css 스타일, src/story.ts 에피소드와 판정, api/story.ts Gemini 서버, src/assets.ts 이미지 연결.

## 검증 및 제한
2026-11-06: 빌드와 테스트 13개 통과(이전 버전 회귀 테스트 포함). 실제 EP01 API가 Gemini 모드 HTTP 200, ready=true, emotion=reassured로 응답했습니다. 전체 브라우저 플레이는 추가 검증이 필요합니다.

민수 기본 생성 이미지를 적용 중입니다. 감정별 원화, 지은·준호 원화, 나머지 장소 배경은 미완료입니다. 기본 이미지의 감정은 현재 UI와 조명으로 표현되며 표정 원화 교체는 아직 아닙니다. 음향 미구현. 기억은 요약 문자열로 저장하며 NPC별 독립 기억 모델은 후속 개선 사항입니다. Mock은 제한된 키워드 기반이므로 Gemini의 의미 분석과 동일하지 않습니다. AI가 반환한 행동 분류의 정확성과 안전 대사는 별도 교육 검수가 필요합니다. 분산 서버 요청 제한 및 배포 검증은 미완료입니다.

## UI 원화 적용 기록 (2026-11-06)
메인 화면 및 복도·계단·출입구·집결지 원화를 동일한 남색/라벤더 애니메이션 배경 지침으로 제작했습니다. 제목·버튼·대사는 코드로 렌더링합니다. src/assets.ts에서 장면을 연결하며 로딩 오류 시 색상 배경으로 복구합니다. 에피소드 선택은 이미지 카드, 결과 창은 집결지 배경을 사용합니다. 이 작업은 UI 배경 개편이며 지은·준호 및 감정별 캐릭터 원화는 포함하지 않습니다.
